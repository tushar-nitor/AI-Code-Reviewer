# 🚀 AI Code Reviewer  
### _Automated Code Review • PR Insights • Smart Refactoring_  

An intelligent **AI-powered code review system** built using **Genkit** for backend agent workflows and **Flutter** for a smooth, interactive frontend experience.  
The tool helps developers automatically **review code blocks**, **analyze GitHub PRs**, provide **line-level suggestions**, and even **apply fixes directly to code** through automated refactoring.

---

## ✨ Features

### 🔍 1. Code Block Review  
- Paste any code snippet  
- Get instant AI-driven feedback  
- Detect anti-patterns, performance issues, and bad practices  
- Highlights improvements line-by-line

---

### 🔗 2. GitHub PR Review  
- Connect your GitHub repo  
- Fetch active Pull Requests  
- Auto-analyze updated files  
- Get summaries, risk areas, and suggested improvements

---

### 💡 3. File Change Insights  
- Shows AI-generated suggestions based on file diffs  
- Explains why a line of code should be updated  
- Highlights:  
  - security issues  
  - complexity  
  - deprecated usage  
  - code smells  
  - duplication

---

### 🔧 4. Apply Suggestions (Auto-Refactoring)  
- Apply individual or bulk suggestions  
- Generates updated/refactored code  
- View “Before vs After” changes in Diff mode  
- Export updated file(s) or push changes to GitHub (optional)

---

## 🏗️ Tech Stack

---

---

## 🧠 How It Works

### **1️⃣ Developer inputs code block OR selects a GitHub PR**  
Frontend sends request to Genkit backend.

### **2️⃣ Genkit Agent analyzes code**  
Runs through tools:  
- Syntax analysis  
- Code quality evaluation  
- Security checks  
- Complexity evaluation  
- Refactoring engine

### **3️⃣ Suggestions returned to frontend**  
Displayed in a clean, structured UI.

### **4️⃣ User applies suggestions**  
System regenerates updated code and shows final diff.
